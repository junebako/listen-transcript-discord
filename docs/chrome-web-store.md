# Chrome Web Store 掲載情報

デベロッパーダッシュボード (https://chrome.google.com/webstore/devconsole) の各タブに、ここから順番にコピペしていけば提出できる状態のまとめ。

## 事前準備

```
npm run package
```

で `listen-transcript-discord.zip` が生成される。「新しいアイテム」からこれをアップロードすると下書きができ、以下のタブが編集できるようになる。

なお「概要」(一覧やヘッダーに出る短い説明) は入力欄がなく、**manifest.json の `description` がそのまま使われる**。

## タブ 1: パッケージ

- `listen-transcript-discord.zip` をアップロードするだけ

## タブ 2: ストア掲載情報

### 説明 (詳細説明の欄)

```
LISTEN (listen.style) の文字起こしを編集したとき、その内容を Discord の Webhook へ自動で通知する拡張機能です。

編集作業を複数人でやっているとき、「どこをどう直したか」をいちいち手で共有するのは面倒です。それをこの拡張機能に任せられます。

■ できること
・文字起こしエディタとエピソードページの両方の編集を検知します
・テキスト編集 / セグメントの結合 / 分割 / 話者変更 / 一括置換を種別ごとに判別して通知します
・通知先は番組ごとに設定します。登録していない番組では何も通知しません
・1 回の保存を 1 通の Discord メッセージ (embed) にまとめます
・変更ごとの見出しが、その時刻から聴けるリンクになっています

■ 使い方
1. Discord で通知先チャンネルの Webhook URL を作成します (チャンネルの設定 → 連携サービス → ウェブフック)
2. LISTEN の番組ページかエピソードページを開いて、ツールバーの拡張機能アイコンをクリックします
3. Webhook URL を貼り付けて「この番組を登録」を押します
4. あとは普段どおり文字起こしを編集するだけです

■ データの扱い
編集内容はあなたが設定した Discord Webhook にだけ送信されます。開発者のサーバは存在せず、アクセス解析やトラッキングもありません。設定 (Webhook URL と表示名) は Chrome の同期ストレージにのみ保存されます。

ソースコードは GitHub で公開しています:
https://github.com/junebako/listen-transcript-discord
```

## タブ 3: プライバシーへの取り組み

### 単一用途の説明

```
LISTEN (listen.style) 上での文字起こしの編集を検知し、その差分をユーザーが設定した Discord Webhook へ通知します。すべての権限はこの単一の目的のためだけに使用します。
```

### 権限ごとの理由 (それぞれ個別の入力欄がある)

**storage の理由:**

```
番組ごとに設定する Discord Webhook URL と、通知に表示する任意の表示名を保存するために使用します。保存先は chrome.storage.sync のみで、外部サーバには保存しません。
```

**ホスト権限 (host_permissions) の理由:**

```
https://listen.style/*: 文字起こしの編集操作を検知するため、LISTEN のページに content script を挿入します。編集の保存リクエストを監視して差分を算出することが目的で、これ以外の情報は読み取りません。

https://discord.com/api/webhooks/*: 算出した差分を、ユーザー自身が設定した Discord Webhook へ POST するために使用します。送信先はユーザーが明示的に登録した Webhook のみです。
```

**リモートコードを使用していますか:** いいえ

### データ使用 (チェックボックス)

- **「ウェブサイト コンテンツ」にチェック** (文字起こしの編集内容を、ユーザーが設定した Discord Webhook へ送信するため)
- それ以外 (個人を特定できる情報、健康、財務、認証情報、個人的な通信、位置情報、ウェブの閲覧履歴、ユーザーアクティビティ) は **チェックしない**

### 3 つの開示認定 (すべてチェックする)

- 承認されている用途以外で、ユーザーデータを第三者に販売または譲渡しません
- アイテムの単一目的に関係のない目的で、ユーザーデータを使用または譲渡しません
- 信用力を判断する目的や融資目的で、ユーザーデータを使用または譲渡しません

## アカウント設定 (初回のみ)

- デベロッパー登録料 $5 (一回のみ)
- 連絡先メールアドレスを登録して確認メールを踏む
- トレーダー申告: **非トレーダー** (個人の非営利提供なので)

## 審査の注意点

- 限定公開でも審査はある。MAIN world への script 注入と `document_start` 実行があるので、審査に数日かかる可能性あり
- 審査で問い合わせが来たら、単一用途の説明と権限ごとの理由をベースに回答する
