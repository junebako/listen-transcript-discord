# Chrome Web Store 掲載情報

デベロッパーダッシュボード (https://chrome.google.com/webstore/devconsole) に入力する内容のまとめ。

## パッケージ

```
npm run package
```

で `listen-transcript-discord.zip` が生成される。これをアップロードする。

## ストア掲載情報

- **名前**: LISTEN 文字起こし編集 Discord 通知
- **カテゴリ**: 仕事効率化 (ツール)
- **言語**: 日本語
- **公開範囲**: 限定公開 (リンクを知っている人のみ)

### 概要 (132 文字以内)

> LISTEN の文字起こしを編集すると、その差分を番組ごとに設定した Discord Webhook へ自動で通知します。複数人での編集作業の共有が楽になります。

### 詳細説明

> LISTEN (listen.style) の文字起こしを編集したとき、その内容を Discord の Webhook へ自動で通知する拡張機能です。
>
> 編集作業を複数人でやっているとき、「どこをどう直したか」をいちいち手で共有するのは面倒です。それをこの拡張機能に任せられます。
>
> ■ できること
> ・文字起こしエディタとエピソードページの両方の編集を検知
> ・テキスト編集 / セグメントの結合 / 分割 / 話者変更 / 一括置換を種別ごとに判別して通知
> ・通知先は番組ごとに設定。登録していない番組では何も通知しない
> ・1 回の保存を 1 通の Discord メッセージ (embed) にまとめる
> ・変更ごとの見出しが、その時刻から聴けるリンクになっている
>
> ■ 使い方
> 1. LISTEN の番組ページを開いてツールバーのアイコンをクリック
> 2. Discord の Webhook URL を入れて「この番組を登録」
> 3. あとは普段どおり文字起こしを編集するだけ

## プライバシー関連の申告

### 単一用途の説明 (single purpose)

> LISTEN (listen.style) 上での文字起こし編集を検知し、その差分をユーザーが設定した Discord Webhook へ通知する。

### 権限の理由

| 権限 | 理由 |
| --- | --- |
| `storage` | 番組ごとの Discord Webhook URL と表示名の設定を保存するため |
| `https://listen.style/*` | 文字起こしの編集操作を検知する content script を LISTEN のページに挿入するため |
| `https://discord.com/api/webhooks/*` | ユーザーが設定した Discord Webhook へ通知を送信するため |
| リモートコード | 使用しない |

### データ使用 (Data usage) のチェック項目

- 「ウェブサイトのコンテンツ」を収集する: **はい** (文字起こしの編集内容を、ユーザーが設定した Discord Webhook へ送信するため)
- それ以外 (個人情報、健康、財務、位置情報、ユーザーアクティビティ等): いいえ
- データの用途: アプリの主要機能のためのみ。第三者への販売・譲渡なし、信用情報目的の利用なし

### プライバシーポリシー URL

リポジトリの `PRIVACY.md` を公開 URL で参照できるようにして、その URL を入力する。

## 必要な画像

| 種類 | サイズ | 状態 |
| --- | --- | --- |
| アイコン | 128x128 PNG | `icons/icon-128.png` |
| スクリーンショット (1 枚以上必須) | 1280x800 または 640x400 | 要作成 |
| 小プロモタイル (任意) | 440x280 | 任意 |

## 審査の注意点

- 初回登録時にデベロッパー登録料 $5 (一回のみ) が必要
- 限定公開でも審査はある。MAIN world への script 注入と `document_start` 実行があるので、審査に数日かかる可能性あり
- 審査で問い合わせが来たら、単一用途の説明と権限の理由をベースに回答する
