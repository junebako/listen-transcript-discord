# LISTEN 文字起こし編集 Discord 通知

[LISTEN](https://listen.style) の文字起こしを編集したとき、その内容を Discord の Webhook へ自動で通知する Chrome 拡張機能です。

編集作業を複数人でやっているとき、「どこをどう直したか」をいちいち手で共有するのは面倒です。それを拡張機能に任せます。

## できること

- 文字起こしエディタ (`/transcript_editor`) とエピソードページの両方の編集を検知する
- テキスト編集 / セグメントの結合 / 分割 / 話者変更 / 一括置換 を種別ごとに判別して通知する
- 通知先は**番組ごと**に設定する。登録していない番組では何も通知しない
- 1 回の保存を 1 通の Discord メッセージにまとめる (embed 形式)

## インストール

1. このリポジトリをクローンする
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」を ON にする
4. 「パッケージ化されていない拡張機能を読み込む」からこのディレクトリを選ぶ

## 設定

### 番組を登録する

LISTEN の番組ページかエピソードページを開いた状態でツールバーのアイコンをクリックすると、その番組の登録画面が出ます。Discord の Webhook URL を入れて「この番組を登録」を押すだけです。

まとめて管理したいときは、popup 下部の「登録済みの番組を管理する」から設定ページを開いてください。番組の追加・削除と、番組ごとのテスト送信ができます。

### 表示名

「junebokuが 3 件を編集しました」のように、通知の要約の頭に付く名前です。空のままだと名前を付けずに「3 件を編集しました」と通知します。

なお Discord 上の投稿者名は「文字起こし編集」で固定です。

## 通知の見た目

1 回の保存につき embed が 1 つ届きます。

- エピソードタイトルがリンクになっている
- 要約は「junebokuが 3 件を編集しました」のように、誰が何件どう変えたかが 1 行で分かる
- 変更ごとに `00:12:32 編集` という見出しが付き、**その見出し自体がその時刻から聴けるリンク**になっている
- 変更前後は diff 形式で色分けされる
- 変更が多いときは 10 件まで並べ、残りは件数だけ伝える

## 仕組み

文字起こしエディタは、保存のたびに**全セグメントをまるごと** `PUT .../transcript_editor/replace_segments` へ送ります。テキスト編集も結合も分割も、すべてこの 1 つのエンドポイントを通ります。

そこでこの拡張機能は、メインワールドで `fetch` をフックして送信内容を捉え、直前のセグメント一覧と突き合わせて差分を算出します。基準となる最初のセグメント一覧は、ページの Alpine.js の state から読み取ります。

エピソードページ側は `POST .../update_body` と Livewire の一括置換フォームを見ています。

検知の経路は 2 系統ありますが、どちらも同じ形に正規化してから通知処理へ渡すので、通知側は経路を意識しません。

詳しくは [設計ドキュメント](docs/superpowers/specs/2026-07-31-listen-transcript-discord-design.md) を参照してください。

## 開発

差分算出とメッセージ組み立ては DOM にも Chrome API にも依存しない純粋関数にしてあり、Node の標準テストランナーで動きます。

```
npm test
```

| ファイル | 役割 |
| --- | --- |
| `src/diff.js` | セグメント差分の算出 |
| `src/message.js` | Discord embed の組み立て |
| `src/listen-url.js` | LISTEN の URL 解析 |
| `src/page-hook.js` | メインワールドでの `fetch` フック |
| `src/content.js` | ページ情報の取得と拡張機能側への橋渡し |
| `src/background.js` | Discord への送信 |
| `src/settings.js` | 設定の読み書き |
